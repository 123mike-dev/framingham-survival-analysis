# Survival Analysis of Cardiovascular Risk – Framingham Study

## 📌 Project Overview
This project applies survival analysis techniques to study the time until cardiovascular disease occurs using the Framingham dataset.

## 🎯 Objectives
- Analyze time-to-event data
- Estimate survival probabilities
- Identify key risk factors

## 📊 Methods Used
- Kaplan-Meier Estimator
- Log-Rank Test
- Cox Proportional Hazards Model

## 🧪 Tools & Libraries
- Python
- pandas
- lifelines
- matplotlib

## ▶️ How to Run
1. Install dependencies:
```
pip install -r requirements.txt
```
2. Open the notebook:
```
jupyter notebook notebooks/survival_analysis.ipynb
```

## 📈 Expected Output
- Survival curves
- Hazard ratios
- Risk interpretation

## 📌 Conclusion
This project demonstrates how survival analysis can be applied to real-world healthcare data to predict cardiovascular risk.
